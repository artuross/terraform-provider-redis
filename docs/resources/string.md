# redis_string (Resource)

Manages a Redis [string](https://redis.io/docs/latest/develop/data-types/strings/), e.g. configuration meant to be read
by clients and only ever changed through Terraform.

Uses following commands:

- `SET key value NX` to create a string, an existing key is never overwritten (delete it first, or import it),
- `SET` to update the value,
- `GET` to read the value, changes made outside Terraform are reverted,
- `DEL` to delete a string.

## Example usage

```terraform
# configuration read by the clients, e.g. with `GET app:config`
resource "redis_string" "config" {
  key = "app:config"
  value = jsonencode({
    feature_flags = { new_checkout = true }
    max_items     = 50
  })
}
```
