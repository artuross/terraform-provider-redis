# redis_function_library (Resource)

Manages a Redis [function library](https://redis.io/docs/latest/develop/programmability/functions-intro/).

Uses following commands:

- `FUNCTION LOAD` to load a function library,
- `FUNCTION LOAD REPLACE` to replace an existing function library,
- `FUNCTION DELETE` to delete a function library.

## Example usage

```terraform
resource "redis_function_library" "counters" {
  content = file("${path.module}/counters.lua")
}
```

`counters.lua`:

```lua
#!lua name=counters

-- FCALL count 1 <key> [increment]
local function count(keys, args)
	return redis.call('INCRBY', keys[1], tonumber(args[1] or 1))
end

redis.register_function('count', count)
```
